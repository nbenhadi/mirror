# /say

Sends a plain text message as the bot in the current channel. Admin only.

## Usage

Run `/say` in the channel where you want to post. A modal opens with a text area. Write the message and submit.

## Notes

- Supports Discord markdown: `**bold**`, `*italic*`, `__underline__`, `~~strikethrough~~`, `` `code` ``, code blocks, and newlines.
- Maximum 2000 characters.
- The command message itself is not visible to other members (ephemeral reply).
- Requires `Administrator` permission.
