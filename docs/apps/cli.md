# CLI reference

The CLI binary is `mir-cli`. Non-interactive interface for scripting and quick access.

## Usage

```bash
mir-cli <tool> <action> [options]
```

## Global options

| Flag            | Description   |
| --------------- | ------------- |
| `-V, --version` | Print version |
| `-h, --help`    | Show help     |

## Tools

Each tool has its own command reference in [docs/tools/](../tools/). Run `mir-cli <tool> --help` for a quick reference inline.
